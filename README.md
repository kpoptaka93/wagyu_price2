# Git Lesson

## リモートリポジトリとローカルリポジトリとはそれぞれ何でしょうか？
- リモートリポジトリ➡︎GitHubを使ったネット上での記録を保管するところです。
- ローカルリポジトリ➡︎自分のパソコン上での記録を保管するところです。

## プッシュとマージの違いは何でしょうか？
- push➡︎ローカルリポジトリで変更して箇所をリモートリポジトリに共有する作業です。
- merge➡︎作業ブランチの変更内容をmainブランチに反映させる作業です。



## コミットとプッシュの違い
- commit➡変更した内容を保存する作業です。
- push➡︎変更した内容をリモーロリポジトリに送信する作業です。



## コミットのメッセージはどのように書いてあげるのが最適でしょうか？
- 変更した内容を明確に簡潔に書いて、誰がみても変更内容がわかるように記入します。



## ローカルでマージするフローと、プルリクエストでマージするフローの違いは何でしょうか？
- 自分のパソコンでコマンドを使って自分でmergeするか、ネット上で自分以外のチェックをしてからmergeをするかの違いです。



## コンフリクトを起こしてしまった場合、どう対処すべきですか？
- 相手と相談してどちらを残すか決める、どちらも必要な情報の場合は綺麗にコードを書き直す必要があります。
